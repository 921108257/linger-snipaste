# 截图交互

主流程遵循 Snipaste：F1 读取一次桌面图像，直接进入无边框全屏冻结画面。鼠标悬停预览容器，滚轮切换嵌套范围，单击选中；拖动使用自由框选，松开后显示悬浮工具栏。主流程没有工作台、历史侧栏和页头。

原始桌面是视觉主体。深灰工具栏 #25282F、青绿选区 #46BAAD、标注红 #EF5350、浅色文字 #F7F8FA。字体为本机 Ubuntu / Noto Sans CJK SC，尺寸使用等宽数字。

选区外压暗；细边框与八个边角控制点表达可调整区域。控制点视觉尺寸 7px、鼠标命中区域 22px。选区内部拖动裁剪范围；文字和形状优先命中，可独立移动。选中标注时，标注外围显示自己的八个缩放控制点，选区手柄暂时停用，Esc 或空白处取消标注选中。

文字输入完成后自动选中，支持移动、缩放和双击编辑。橡皮擦显示尺寸圆圈，只合成在标注图层上；截图原图位于独立图层。撤销恢复整个标注状态。

工具栏优先放在选区下方，空间不足则放到上方；全屏时浮在边缘，按实际工具栏高度避开屏幕边界。导出使用独立的原始像素渲染，排除遮罩、边框、控制点与工具栏。

GNOME 46 由用户明确启用的配套桌面扩展执行单次取图，不打开系统 ScreenshotUI。扩展核验 Linger 后台子进程身份，锁屏及系统禁止保存截图时拒绝取图；未启用时返回设置提示。其他桌面使用非交互 Screenshot Portal，失败不会自动重试交互模式。取得截图后，OpenCV 依据轮廓和表面阈值识别窗口内部的可见矩形区域；归一化坐标用于映射不同截图尺寸与视口。该识别不依赖 DOM/可访问性树，不保证识别无边界或复杂背景中的元素。

应用自启动静默驻留托盘，托盘提供截图、贴图、设置与退出。设置窗口去掉系统标题栏，通过内部标题区拖动；浅色半透明背景与青绿开关 #247C70 呈现快捷键、直接截图、自动识别与自启动选项。配套扩展仅对 Linger 设置窗口添加合成器背景模糊。使用本机 Ubuntu / Noto Sans CJK SC 字体，内容左对齐，控件右对齐。“收起到托盘”位于“保存设置”左侧，隐藏窗口后保持后台运行。全局快捷键在保存时注册，冲突及保存失败会保留原值。
